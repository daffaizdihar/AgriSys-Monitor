# 🌾 AgriSys Monitor

**AgriSys Monitor** is a beginner-friendly Linux terminal application built using Bash scripting. It is designed to help users, specifically beginner farmers and students, manage simple farming activities through a Command Line Interface (CLI). 

To maintain simplicity and adhere to our academic project constraints, this system does not rely on complex databases, IoT sensors, or AI. Instead, it uses standard Linux file handling, storing all data safely in plain text files.

## ✨ Core Features
* **Interactive Main Menu:** A fully functional CLI menu driven by Bash `while` loops and `case` statements for easy navigation.
* **Add Farm Data (Scientifically Backed):** Users can input their land size, and the system will automatically calculate water (Liters) and fertilizer (Kg) requirements. The logic uses the `bc` command and is backed by real-world agronomic data from the FAO and the Indonesian Ministry of Agriculture for 10 specific crops (Padi, Jagung, Cabai, Tomat, Sawi, Bayam, Kangkung, Kentang, Wortel, Kubis).
* **View Database:** Displays all saved plant data directly in the terminal using Linux text processing commands.
* **Search & Monitor:** Uses advanced `awk` and `grep` string manipulation to search for specific plant data. It dynamically calculates the remaining days until harvest and generates specific watering and fertilizing schedules based on the input date.
* **Clear Database:** Safely manages file storage by allowing users to either delete specific data entries or clear the entire database.

## 📂 Project Structure
This application is built using a modular Bash design. The features are separated into distinct script files and linked using the `source` command:
* `main.sh` — The core execution script and main navigation menu.
* `config.sh` — Initializes the system and the database text file.
* `add_farm.sh` — Handles user input and contains the core mathematical logic for plant requirements.
* `view_data.sh` — Reads and outputs the saved data.
* `search_data.sh` — Parses text to search the database and calculates monitoring estimates.
* `clear_data.sh` — Handles file deletion and database resets.
* `farm_database.txt` — The plain text storage file automatically generated by the system.

## ⚙️ Technologies & Linux Modules Used
* **Operating System:** Ubuntu Linux.
* **Programming Language:** Bash Shell Scripting.
* **Terminal Commands:** `mkdir`, `cat`, `echo`, `grep`, `awk`, `bc`, `chmod`.
* **Course Modules Applied:** Basic Scripting, Command Line Skills, Managing Files & Directories, and Working with Text.

## 🚀 How to Run
1. Clone this repository to your local Ubuntu Linux machine or Virtual Machine.
2. Ensure you have the Basic Calculator package installed for the formula logic to work:
   ```bash
   sudo apt install bc
   ```
3. Make all the shell scripts executable by changing their permissions:
   ```bash
   chmod +x *.sh
   ```
4. Run the application:
   ```bash
   ./main.sh
   ```
